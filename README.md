Веб-приложение для конвертации Excel-файлов, построения сводных таблиц, работы со справочниками, AI-чата на базе DeepSeek и управления задачами.

---

## Возможности

### 📊 Конвертер Excel
- Загрузка Excel-файлов (`.xlsx`, `.xls`, `.csv`) и конвертация с использованием профилей маппинга
- Автоопределение типов колонок
- Статистика по обработанным данным
- Предпросмотр результата перед скачиванием
- Профили маппинга — сохранение схем конвертации для повторного использования

### 🏢 Справочники
- Управление подразделениями через веб-интерфейс
- Управление статьями расходов

### 📈 Визуализатор графиков
- **15+ типов диаграмм**: столбчатые, линейные, круговые, специальные (радар, точечная, пузырьковая, тепловая карта, комбинированная)
- **Цветовые схемы**: 6 палитр на выбор
- **Стили отображения**: 2D, 3D-эффект, минималистичный
- **Гибкие настройки**: прозрачность, толщина линии, легенда, подписи данных, сетка, анимация
- Экспорт графика в PNG одним кликом
- Поддержка многорядных данных

### 🔧 Конструктор сводных таблиц (Low-code)
- Загрузка Excel-файлов без предварительной настройки
- Автоопределение заголовков
- Визуальный просмотр данных с сортировкой и фильтрацией
- Построение сводных таблиц с произвольным выбором строк, колонок и значений
- Множественные функции агрегации (sum, avg, count, min, max)
- Плоский или иерархический формат вывода
- Итоги по строкам и столбцам
- Декомпозиция дат (год, квартал, месяц, день недели)
- Сохранение и загрузка сценариев построения
- Экспорт результата в XLSX

### 💬 DeepSeek AI Chat
- Интеграция с DeepSeek API
- Потоковый вывод ответов
- Загрузка изображений с распознаванием текста
- Загрузка текстовых файлов для анализа
- Поддержка Markdown-разметки в ответах
- Управление историей диалогов

### 📋 Блокнот задач
- Создание, редактирование, выполнение и отмена задач
- Автоматическая архивация выполненных и отменённых задач
- Группировка архива по дню/месяцу/году
- Кликабельные ссылки в тексте задач

### 🛡️ Безопасность
- CSRF-защита всех мутирующих запросов
- Ограничение частоты запросов на авторизацию

### 🎨 Интерфейс
- Тёмная и светлая темы с сохранением выбора
- Адаптивная вёрстка

### 🔄 Автообновление
- Автоматическая проверка обновлений на GitHub
- Уведомление о новой версии с описанием изменений
- Установка обновления через веб-интерфейс
