---

## Возможности

### 📊 Конвертер Excel
- Загрузка Excel-файлов (`.xlsx`, `.xls`, `.csv`) и конвертация с использованием профилей маппинга
- Автоопределение типов колонок
- Статистика по обработанным данным
- Предпросмотр результата перед скачиванием
- Профили маппинга — сохранение схем конвертации для повторного использования

### 🏢 Справочники
- **Подразделения** — редактирование через веб-интерфейс (добавление, изменение, удаление)
- **Статьи расходов** — справочник с возможностью управления записями

### 🔧 Конструктор сводных таблиц (Low-code)
- Загрузка любого Excel-файла без предварительной настройки
- Автоопределение строки заголовков
- Визуальный просмотр данных с сортировкой и фильтрацией
- **Построение сводных таблиц (pivot)**:
  - Произвольный выбор строк, колонок и значений
  - Множественные функции агрегации (sum, avg, count, min, max)
  - Плоский или иерархический формат вывода
  - Итоги по строкам и/или столбцам
- Декомпозиция дат (год, квартал, месяц, день недели)
- Сохранение и загрузка сценариев построения
- Экспорт результата в XLSX

### 💬 DeepSeek AI Chat
- Интеграция с DeepSeek API
- Потоковый вывод ответов (streaming)
- Загрузка изображений с распознаванием текста (EasyOCR)
- Загрузка текстовых файлов для анализа
- Поддержка Markdown-разметки в ответах
- Управление историей диалогов (создание, переименование, удаление)

### 📋 Блокнот задач
- Создание, редактирование, выполнение и отмена задач
- Автоматическая архивация выполненных и отменённых задач
- Группировка архива по дню/месяцу/году
- Сворачивание групп с отображением количества задач
- Кликабельные ссылки в тексте задач

### 🛡️ Безопасность (v1.2.0+)
- **CSRF-защита** — все мутирующие запросы (POST/PUT/PATCH/DELETE) защищены через Flask-WTF CSRFProtect
- Токен передаётся в заголовке `X-CSRFToken`, обновляется после входа
- Rate limiting на `/api/login` (5 запросов в минуту)

### 🎨 Интерфейс
- **Тёмная и светлая темы** — переключение в один клик, выбор сохраняется в `localStorage`
- **Адаптивная двухколоночная вёрстка**
- **Автообновление** — приложение само проверяет наличие новой версии на GitHub

### 🔄 Система автообновления

- Периодическая проверка обновлений (раз в 6 часов)
- Уведомление о доступной новой версии с описанием изменений
- Автоматическое скачивание и установка обновления через веб-интерфейс
- Перезапуск сервера после установки
- Ручная проверка по клику на версию приложения

## Установка

### Требования
- Python 3.8+
- pip

### Шаги

1. **Клонировать репозиторий:**
```bash
git clone https://github.com/Dgigin/Personal-assistant.git
cd Personal-assistant
```

2. **Создать виртуальное окружение:**
```bash
python -m venv venv
venv\Scripts\activate  # Windows
source venv/bin/activate  # Linux/Mac
```

3. **Установить зависимости:**
```bash
pip install -r requirements.txt
```

4. **Настроить `.env` файл:**
```env
SECRET_KEY=ваш_секретный_ключ
AUTH_ENABLED=true
AUTH_USERNAME=admin
AUTH_PASSWORD=ваш_пароль
DEEPSEEK_API_KEY=ваш_ключ_deepseek
```

5. **Запустить:**
```bash
python app.py
```

Приложение будет доступно по адресу `http://127.0.0.1:5000`.

### Production-запуск
```bash
python wsgi.py
```
Использует Waitress (Windows) или Gunicorn (Linux).

## Технологии

| Компонент | Технология |
|-----------|-----------|
| Веб-фреймворк | Flask |
| WSGI-сервер | Waitress / Gunicorn |
| База данных | SQLite (чат), JSON (задачи, справочники) |
| OCR | EasyOCR |
| AI-чат | DeepSeek API (streaming) |
| Фронтенд | Vanilla JS SPA |
| Планировщик | APScheduler |
| CSRF-защита | Flask-WTF 1.2.2 |
| Rate limiting | Flask-Limiter 4.1.1 |
| Сборка установщика | Inno Setup |
