# Excel Converter

Веб-приложение для конвертации Excel-файлов, построения сводных таблиц, работы со справочниками и AI-чата.

## Возможности

### 📊 Конвертер Excel
- Загрузка Excel-файлов и конвертация с использованием профилей маппинга
- Автоопределение типов колонок
- Статистика по обработанным данным

### 📁 Профили
- Создание и редактирование профилей маппинга колонок
- Сохранение схем конвертации для повторного использования

### 🏢 Справочники
- Справочник подразделений (188 записей)
- Справочник статей расходов
- Редактирование через веб-интерфейс

### 🔧 Конструктор сводных таблиц (Low-code)
- Загрузка любого Excel-файла
- Автоопределение строки заголовков
- Визуальный просмотр данных с сортировкой и фильтрацией
- Построение сводных таблиц (pivot):
  - Выбор строк, колонок и значений
  - Множественные функции агрегации (sum, avg, count, min, max)
  - Плоский или иерархический формат вывода
  - Итоги по строкам/столбцам
- Декомпозиция дат (год, квартал, месяц, день)
- Сохранение и загрузка сценариев
- Экспорт в XLSX

### 💬 DeepSeek AI Chat
- Интеграция с DeepSeek API
- Потоковый вывод ответов
- Загрузка изображений с распознаванием текста (EasyOCR)
- История диалогов

### 📋 Блокнот задач
- Управление задачами (создание, редактирование, выполнение, отмена)
- Автоматическая архивация выполненных задач
- Группировка архива и отменённых задач по дню/месяцу/году
- Сворачивание групп с отображением количества задач
- Кликабельные ссылки в тексте задач

## Установка

### Требования
- Python 3.8+
- pip

### Шаги

1. Клонировать репозиторий:
```bash
git clone https://github.com/yourusername/excel_converter.git
cd excel_converter
```

2. Создать виртуальное окружение:
```bash
python -m venv venv
venv\Scripts\activate  # Windows
source venv/bin/activate  # Linux/Mac
```

3. Установить зависимости:
```bash
pip install -r requirements.txt
```

4. Настроить `.env` файл:
```env
SECRET_KEY=ваш_секретный_ключ
AUTH_ENABLED=true
AUTH_USERNAME=admin
AUTH_PASSWORD=ваш_пароль
DEEPSEEK_API_KEY=ваш_ключ_deepseek
```

5. Запустить:
```bash
python app.py
```

Приложение будет доступно по адресу `http://127.0.0.1:5000`.

### Production-запуск
```bash
python wsgi.py
```
Использует Waitress (Windows) или Gunicorn (Linux).

## Технологии

| Компонент | Технология |
|-----------|-----------|
| Веб-фреймворк | Flask |
| WSGI-сервер | Waitress / Gunicorn |
| База данных | SQLite (чат), JSON (задачи, справочники) |
| OCR | EasyOCR |
| AI-чат | DeepSeek API (streaming) |
| Фронтенд | Vanilla JS SPA |
| Планировщик | APScheduler |
