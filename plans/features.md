## 🔄 Конвертер Excel

### Назначение

Конвертирует Excel-файлы (.xlsx/.xls/.csv) по заданному профилю маппинга, сопоставляя исходные колонки с целевыми.

### Как работает

1. Пользователь загружает Excel-файл и выбирает профиль маппинга
2. Система показывает статистику: какие колонки будут сопоставлены, какие останутся неизвестными
3. Пользователь может сопоставить неизвестные колонки вручную
4. Результат скачивается в формате XLSX

### API-эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| POST | `/api/columns` | Получить колонки загруженного файла |
| POST | `/convert/stats` | Статистика по файлу |
| POST | `/convert/preview` | Предпросмотр конвертации |
| POST | `/convert/download` | Скачать результат |

### Профили маппинга

Хранятся в `profiles/*.json`. Каждый профиль содержит соответствие "исходная колонка → целевая колонка", настройки группировки и трансформации.

## 🔧 Конструктор сводных таблиц

### Назначение

Low-code инструмент для построения сводных таблиц из Excel/CSV-файлов без программирования.

### Возможности

1. **Загрузка файла** — выбор .xlsx, .xls, .csv
2. **Автоопределение заголовков** — умное распознавание строки с заголовками колонок
3. **Транспонирование** — поддержка данных, где строки и колонки поменяны местами
4. **Фильтрация** — 7 типов фильтров: equals, contains, not_equals, greater_than, less_than, is_empty, is_not_empty
5. **Группировка данных** — выбор строк, колонок и значений для сводной
6. **Мульти-агрегация** — несколько функций агрегации одновременно (sum, avg, count, min, max, none)
7. **Форматы вывода** — плоский (широкий) и иерархический (вертикальный)
8. **Режимы итогов** — без итогов, по строкам, по столбцам, по строкам и столбцам
9. **Декомпозиция дат** — авто-разбивка datetime на год/квартал/месяц/день
10. **Сценарии** — сохранение/загрузка/удаление настроек сводной
11. **Экспорт** — скачивание результата в XLSX

### API-эндпоинты (12 шт.)

| POST | `/api/constructor/load` | Загрузить лист, получить данные + колонки + типы |

### Спецификация конструктора v2 (4 задачи)

#### 1. Декомпозиция datetime

- Авто-определение date-колонок через `_parse_dates_flexible()`
- Суб-опции (год/квартал/месяц/день) в мультиселектах
- Виртуальные колонки с префиксами `__год__`, `__квартал__`, `__месяц__`, `__день__`

#### 2. Агрегация "Без изменений"

- Опция `value="none"` — возвращает сырые данные без агрегации
- Плоская таблица с выбранными колонками

#### 3. Сохранение сценариев

- JSON-файлы в `config/constructor_scenarios/{name}.json`
- Полный цикл: save/load/list/delete
- Восстановление всех параметров (колонки, фильтры, pivot, header_row)

#### 4. Мульти-агрегация

- Выбор нескольких функций агрегации одновременно
- Два формата вывода: плоский (широкий) и иерархический (вертикальный)
- `<select multiple>` + переключатель формата

### Оптимизация загрузки (v1.0.7)

**Проблема:** При загрузке "тяжёлых" .xlsx файлов (>1 МБ) `load_sheet_data()` читал весь файл, даже если нужно всего 100 строк.

**Решение:** Параметр `nrows=limit+offset` — читается только необходимое количество строк.

```python
# Было:
df = pd.read_excel(file_path, sheet_name=sheet_name, header=header_row, dtype=str)

# Стало:
df = read_file_to_df(file_path, sheet_name=sheet_name, header=header_row,
                     dtype=str, nrows=limit + offset + 1)
```

## 🔄 Автообновление через GitHub Releases

### Созданные файлы (v1.0.4+)

- [`version.json`](version.json) — текущая версия + репозиторий `Dgigin/Personal-assistant`
- [`src/updater.py`](src/updater.py) — модуль с функциями:
  - `get_current_version()` — читает версию из `version.json`
  - `check_for_update()` — GET к `https://api.github.com/repos/{repo}/releases/latest`
  - `download_update(url, progress_callback)` — скачивает ZIP с прогрессом
  - `install_update(zip_path)` — создаёт `apply_update.py`, который распаковывает архив и перезапускает сервер
  - `check_pending_update()` — очищает мусор от прерванных обновлений
- [`src/routes/update_routes.py`](src/routes/update_routes.py) — 4 эндпоинта

### Принцип работы

1. При загрузке страницы — `initUpdateSystem()` вызывает `checkForUpdates()`
2. Если на GitHub есть новый релиз — показывается жёлтый баннер
3. При клике "Обновить" — POST `/api/apply_update` → скачивание ZIP с прогрессом
4. После скачивания — кнопка "🔄 Перезапустить сейчас"
5. `apply_update.py` распаковывает архив, удаляет временные файлы, запускает `python app.py`

### История исправлений механизма обновления

**v1.0.4:** `update.bat` вызывал `tar -xf` → заменён на `python apply_update.py` (zipfile)
**v1.0.5:** Очистка stale файлов при старте (`run.bat`)
**v1.0.6:** Полная переработка — `apply_update.py` перезаписывает `update.bat` перед удалением (Windows не даёт удалить запущенный .bat), никаких `del "%~f0"`

## 🐛 История баг-фиксов

### #20 — datetime в ключах словарей (03.06.2026)

**Проблема:** `TypeError: '<' not supported between instances of 'datetime.datetime' and 'str'` при `jsonify()`.

**Причина:** Excel-файл содержал колонки с заголовками-датами. `pd.read_excel(dtype=str)` возвращала `datetime.datetime`-объекты как ключи словарей. `_sanitize_for_json()` санитизировала только значения, но не ключи.

**Исправление:** [`src/routes/constructor_routes.py:42`](src/routes/constructor_routes.py:42)
```python
# Было:
if isinstance(obj, dict):
    return {k: _sanitize_for_json(v) for k, v in obj.items()}

# Стало:
if isinstance(obj, dict):
    return {_sanitize_for_json(k): _sanitize_for_json(v) for k, v in obj.items()}
```

### #21 — NaT-фильтрация + универсальный парсер дат (03.06.2026)

**Проблема:** Четыре компонента даты (год/квартал/месяц/день) по-разному обрабатывали NaT:
- Месяц: `fillna('')` → пустая строка ✅
- Год: `fillna(0).astype(int).astype(str)` → `"0"` ❌
- Квартал: `'Q' + fillna(0)` → `"Q0"` ❌
- День: `fillna(0).str.zfill(2)` → `"00"` ❌

**Исправление:** `nat_mask = dt_series.isna()`, затем `year_vals[nat_mask] = ''`

### #22 — Режим итогов (totals_mode) (03.06.2026)

**Проблема:** Бинарный переключатель "Итого" (вкл/выкл) добавлял сразу и строку, и колонку.

**Исправление:** 4 режима: `none`, `rows`, `cols`, `both` через post-фильтрацию margins.

### #23 — UI редизайн: segmented buttons (03.06.2026)

**Проблема:** Чекбокс/тоггл "Итого" + радио-инпуты "Плоский/Иерархический" выглядели некрасиво.

**Исправление:** Segmented buttons для итогов (4 режима, оранжевая гамма) и формата (2 режима, зелёная гамма).

### #24 — Автоопределение строки заголовков (03.06.2026)

**Проблема:** `pd.read_excel()` всегда использовал `header=0`. В файлах с заголовками в строке 1 или вообще без заголовков отображались `Unnamed: 0`.

**Исправление:** Функция `_detect_header_row()` + UI-диалог выбора строки + per-sheet кэширование.

### #25 — Поддержка транспонированных данных (03.06.2026)

**Проблема:** Некоторые Excel-файлы хранят данные в транспонированном виде.

**Исправление:** Параметр `transpose: bool = False` в `load_sheet_data()`, UI-чекбокс в диалоге заголовков.

### #31 — Критический багфикс update.bat (v1.0.6)

**Проблема:** `update.bat` содержал `del "%~f0"` — Windows не может удалить запущенный .bat. При ошибке обновления батник оставался и запускался снова при каждом рестарте.

**Исправление:** Перенос всей логики в `apply_update.py`, который перезаписывает `update.bat` на `@exit /b 0` из Python (Python может перезаписать, хотя Windows не даёт удалить).
